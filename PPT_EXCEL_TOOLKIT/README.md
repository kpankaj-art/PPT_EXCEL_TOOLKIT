# PPT & Excel Toolkit

Combined Streamlit dashboard containing 6 PPT/Excel automation tools.

## Usage

1. Run `streamlit run app.py`
2. Select the task on the home screen.
3. Only that tool's upload and processing options appear.
4. Use Home to return to the dashboard.

## Included tools

- Smart PPT + Excel Matcher
- PPT Size Fixer
- PPT Slide Deleter
- PPT Image + Markup Extractor
- SAP / Brand Transfer
- PPT → Excel Client Remarks

## Upload limit

The Streamlit configuration is set to **2048 MB (2 GB)** for both individual uploads and messages.

> Actual hosting/provider, reverse-proxy, browser, or server memory limits can still impose lower practical limits. Large PPT files may require substantial RAM during processing.
