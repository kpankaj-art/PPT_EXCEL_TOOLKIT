# PPT & Excel Toolkit

Six Streamlit tools are combined into one dashboard.

## Tools
1. Smart PPT + Excel Matcher
2. PPT Size Fixer
3. Excel-Based PPT Slide Deleter
4. PPT Image + Markup Extractor
5. SAP / Brand Transfer
6. PPT → Excel Client Remark Extractor

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

The app first asks what task you want to perform. Upload controls appear only after selecting a tool.
